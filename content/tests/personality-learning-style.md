## What It Explores

This activity asks students how they usually react when a task feels new, difficult, or open-ended.

It looks at preferences such as:

- trying first and learning from mistakes
- watching examples before starting
- talking with others to build ideas
- working quietly and organizing notes

## Sample Prompt

When you meet a difficult question, what do you usually do first?

- draw or write what you know
- ask someone to explain the task
- search for a similar example
- try a few possible answers

## How To Use Results

The best outcome is a more precise learning conversation. A student can say, "I need an example first," or "I understand better when I explain my thinking out loud."
